# FKCAC

一个基于 **Minecraft 1.7.10 Forge** 的客户端 Mod 框架，用于在**自建服务器**上做服务端反作弊检测的鲁棒性测试。

> 仅限自建服务器 / 你拥有权限的测试环境使用。

---

## 这是什么

FKCAC 会接管特定反作弊插件所使用的通讯通道，并以“纯净客户端”的视角应答其各类校验。通过观察服务端对不同应答的判定结果，即可验证既有反作弊是否存在可被构造/绕过的检测链路。

- **适配目标**：本项目所针对的、已停止更新的开源版反作弊客户端协议（其商业版本为闭源，不在本项目范围内）。
- **参考来源**：实现时参考了社区公开的开源反作弊源码及其对抗实现，结构与思路经泛化整理，并不逐字照搬、也不引用任何特定仓库或作者。

---

## 已覆盖的测试场景

按目标服务端此前暴露的检测点逐一验证：

- 加入时的客户端 mod 标识校验
- 握手协议版本与随机盐值
- 文件哈希校验（数量与格式约束）
- 类存在性校验（“标记类”须存在、黑名单类须不存在）
- 截图请求
- 周期心跳与原版渲染标志

## 使用方法

1. 关闭游戏，删除 `mods/` 下原同名反作弊客户端 Mod（避免 modid / 通道冲突）。
2. 将 `FKCAC-<version>.jar` 放入客户端的 `mods/` 目录。
3. 使用带 Forge 的 1.7.10 客户端启动并进入测试服务器。

### 配置 `config/fkcac.cfg`

| 项 | 默认 | 说明 |
| --- | --- | --- |
| `protocolVersion` | `2` | 握手上报的协议版本，应与目标服务端一致 |
| `fileHashList` | 空 | 文件哈希上报列表（>5 条去重、`40hexSHA1\0名称`）；留空则自动上报真实启动源哈希 |
| `trustedClasses` | 8 个候选类 | 类校验中报告为“已发现”的类集合；其余一律“未发现” |
| `spoofScreenshot` | `true` | 是否用空白 PNG 应答截图请求 |

## 构建

```bash
./gradlew build            # 使用默认版本
./gradlew build -PmodVersion=1.2.0   # 指定版本
# 产物在 build/libs/
```

CI 工作流（`.github/workflows/build.yml`，`Minecraft 1.7.10 / Forge`）为**纯手动触发**：

1. 在仓库 **Actions** 页手动运行。
2. 填写**版本号**。
3. 如需发布，勾选**「发布」**——构建成功后会自动生成对应版本的 GitHub Release 并附带 Mod 文件。
